ESTETİK FETHİYE — WEB SİTESİ

Sürüm 3: Detaylı botoks, dolgu, mezoterapi, gençlik aşısı,
biyostimülan, eksozom, saç ve IV destek alanları eklenmiştir.

Visual Studio Code ile açma:
1. ZIP dosyasını açın.
2. Visual Studio Code'u çalıştırın.
3. File > Open Folder menüsünden EstetikFethiye klasörünü seçin.
4. Ana site dosyası index.html'dir.

Netlify'a yükleme:
1. Netlify hesabınıza girin.
2. Add new site > Deploy manually seçeneğini açın.
3. ZIP'ten çıkan EstetikFethiye klasörünü yükleme alanına sürükleyin.

Dosya yapısı:
- index.html: Sitenin tüm metin, tasarım ve bağlantıları
- assets/estetik-fethiye-hero.png: Ana sayfa görseli
- assets/cilt-analizi.png: Estetik değerlendirme görseli
- assets/klinik-ortami.png: Klinik yaklaşımı görseli
- netlify.toml: Netlify yayın ayarları
